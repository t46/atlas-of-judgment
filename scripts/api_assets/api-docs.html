CONVENTIONS
How to read a claim
Source vs. derivation vs. verified
Nearly every headline number on this site is an aggregate computed over an array (most often triples[]), not a single JSON leaf. A claim therefore separates the source (which file, which array), the derivation (the arithmetic, stated plainly), and verified (the dated human audit that recomputed it). A pointer pretending to be more precise than that would be less honest, not more.
Caveats attach to claims, not pages
Each claim lists caveat_refs — an empty list is itself an assertion that none apply. The corpus-wide one to know: ICLR changed its rating scale and review form four times over 2018–2026, so any claim comparing scores across years carries the moving-ruler caveat (see method §07, "The moving ruler"). Claims about unit counts and shares — most of the site — are measured by the taxonomy, which is the constant instrument.
Citing
Cite plate id + claim id, e.g. plate-i#1a-negative-share — stable across visual redesigns even when the prose around a number is rewritten. Derived data is CC BY 4.0; the underlying reviews belong to their anonymous authors via OpenReview.
